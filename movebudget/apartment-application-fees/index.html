Application fees add up before you even sign

Application fees are typically non-refundable and charged per adult applicant, so a couple applying to three apartments can spend a meaningful amount before any lease is signed. Ask upfront whether the fee covers a background check only or also an admin/processing charge — some buildings itemize these separately, effectively doubling the "application fee" in practice.

Questions to ask before paying

  • Is the fee refundable if I'm not approved?
  • Does it cover one adult or the whole household?
  • Is there a separate admin fee on top of the application fee?
  • How long is the background check valid if I apply to another unit in the same building?

Frequently asked questions

Is an application fee refundable if I'm rejected?

Usually not — most application fees cover the cost of the background/credit check regardless of outcome. Ask explicitly before paying, since policies vary by landlord and state.

Should I apply to multiple apartments at once to save time?

Only if you can afford the fees for each one. Applying broadly speeds up finding a unit but multiplies non-refundable fees if several come back positive at once.

Is an admin fee the same as an application fee?

Not always — some buildings charge both separately. Ask for an itemized breakdown before paying so you know the real total, not just the advertised application fee.
